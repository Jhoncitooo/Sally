# 🏎️ Cars (2006) - Invitación de Cine Interactiva (08 de Octubre) 🏁⚡

Página web interactiva y didáctica de invitación para ver la primera película de **Cars (Disney Pixar 2006)** el **08 de Octubre**.

## 🌟 Características
- **🎫 Pase VIP Personalizable (Piston Cup Pass)**: Genera y me estampa un pase exclusivo a la función con el nombre de cada invitado.
- **⏱️ Temporizador en vivo**: Cuenta regresiva en formato velocímetro deportivo para el 8 de octubre a las 07:00 PM.
- **💡 Modo Noche Neón**: Alterna entre el tema del desierto y la atmósfera nocturna neón de Radiator Springs.
- **🍿 Menú de Pits (Snacks)**: Selección interactiva de bocadillos (palomitas, refrescos, pizza y dulces).
- **🧠 Trivia de Rayo McQueen**: Minijuego de 3 preguntas con puntuación, trofeo y efectos visuales.
- **⚡ Confirmación RSVP "¡Cuchao!"**: Respuesta interactiva con audio sintetizado de motor y chispas/confeti.

## 🚀 Tecnologías
- HTML5 Semántico
- CSS3 Moderno (Vanilla CSS, animaciones racing, glassmorphism, temas dinámicos)
- JavaScript ES6+ (Sintetizador de sonido con Web Audio API, Canvas Confetti)
